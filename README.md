# Docker CKA Labs

This repository contains a collection of hands‑on practice labs for the **Certified Kubernetes Administrator (CKA)** exam, focusing on Docker fundamentals and related Kubernetes concepts.  Each lab is provided as an individual Markdown file that walks through a specific task, complete with step‑by‑step instructions and code snippets.

## How to Use

1. Open any of the practice Markdown files in a text editor or IDE.
2. Follow the numbered steps; commands are ready to be copied and executed in a terminal.
3. For labs that involve Kubernetes, ensure you have a cluster (e.g., Minikube, Kind, or a cloud‑based cluster) configured and `kubectl` installed.
4. After completing a lab, you can optionally clean up resources using the provided cleanup commands.

## Contributing

Feel free to submit pull requests to add new labs, improve existing instructions, or fix typos.  Ensure each new lab follows the same structure:

- **Practice Guide:** Title and objective.
- **Step‑by‑step commands** with code blocks.
- **Verification** commands to confirm the outcome.
- **Cleanup** instructions.
